# Song sources

The built-in songs in `src/app/data/songs/` are generated by `scripts/build-songs.py` from community transcriptions
(Guitar Pro tabs and MIDI files). The source files are not committed. To rebuild a song, download its file, save it
under the local name below in a folder (default `song-sources/`, git-ignored), and run:

```sh
pip install pyguitarpro mido
SONG_SOURCES=song-sources python3 scripts/build-songs.py <song-id>   # or no id to rebuild all
```

Songs are instruments only: no vocal track is ever used (the converter refuses tracks that look like vocals).
